# Analytical enhancements

This folder contains the reproducible clustering experiments and their generated
outputs. It preserves the original notebook and CSV exports.

To refresh the experiments after changing the input data or analytical code, run:

```powershell
python enhancements\run_algorithm_experiment.py
```

The website has been separated into the project-level `website/` folder for team
handoff. See `website/README.md` for its setup and run instructions.
